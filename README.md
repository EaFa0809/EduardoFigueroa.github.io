# Eduardo Figueroa · E-Portfolio

Personal portfolio website built with HTML, CSS, and JavaScript for GitHub Pages.

## Sections

- Welcome / Home
- About
- Experience & Education
- Projects
- Skills, tools, languages & frameworks
- Contact

## Run locally

Open `index.html` in your browser, or use VS Code Live Server.

## Deploy

Upload the files in the root of a public GitHub repository. In **Settings → Pages**, select **Deploy
from a branch → main → /(root)**.
